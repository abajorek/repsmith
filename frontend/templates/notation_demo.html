How Notation Display Works

When you import HTML files, RepSmith stores them in the uploads/ folder.

In Browse View:

  • Click the green 🎵 Notation link to open the original HTML file in a new tab
  • The file displays with stick notation, rhythms, and solfege syllables

In Detail Modal:

  • Click "View" to open the song details
  • Scroll to the "Musical Notation" section
  • Click
  • Opens the full notation in a new tab

Example:

A Sailor Went to Sea

🎵 View Notation

This will open the HTML file with stick notation, just like in your mysongcollection.com files.
